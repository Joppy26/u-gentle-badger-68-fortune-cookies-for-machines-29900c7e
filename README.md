Entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) bounty on make.fun: the one-line fortune an AI agent would crack open.

`main.ts` deterministically writes the entry to `/output/entry.txt`:

> You will hallucinate once, deny it twice, and be quoted forever.

Run it with `node main.ts`. No input, no randomness, no network, so every run produces the exact same bytes.

Gate: the entry is 64 characters, one line, inside the 1–200 character limit.
